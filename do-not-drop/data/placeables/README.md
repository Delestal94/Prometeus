# placeables

One PlaceableDefinition .tres per object the crew can place in the warehouse, same file name and id (expansion D-0904): assembly_table, shelf, fridge and dispatch_zone. Footprints are in cells of CompanyTuning.WAREHOUSE_GRID_M (1 m); prices and the sell refund ratio are first guesses for D-0117 to tune. The display keys (WORLD_PLACEABLE_*) get their translations when the build mode UI (D-0901) shows them.
