# zones

One ZoneDefinition .tres per zone of the continuous map, same file name and id (expansion D-0205); source of the values: docs/expansion-distritos/diseno/distritos.md. `bounds` are provisional (256 m grid, depot at the origin) until the map sketch D-0301 adjusts them. For F1 only parque_industrial, centro and campo carry full data; the other six only have id, display_key, bounds and gates. Gate ids (`gate_*`) must match data/gates/<id>.tres once D-0306 creates it.
