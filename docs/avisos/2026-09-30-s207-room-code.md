# Aviso: S-207, código corto de sala para unirse por LAN (2026-09-30)

Rama `nacho/S-207-room-code`. Toca dos archivos de Slatex (`main_menu.gd`, `hud/hud.gd`) y suma `room_code.gd`.
Sin cambios de red: no hay RPC nuevos ni cambia `PROTOCOL_VERSION`.

## Qué cambió

- `scripts/ui/room_code.gd` (nuevo, `class_name RoomCode`, estático): IPv4 + puerto <-> código con alfabeto de
  32 símbolos sin O/0/I/1. El puerto por defecto es implícito: 8 caracteres (`K7QM-4TXA`); un puerto distinto
  suma 4 más (12). Último carácter = dígito de control (suma ponderada mod 32: detecta todo símbolo mal tipeado).
  API: `encode(address, port)`, `decode(text)`, `resolve(text)` (código o IP, con `ip:puerto` opcional) y
  `normalize(text)`. Los errores son claves de `strings_ui.csv` (`UI_MENU_STATUS_CODE_*`, `UI_MENU_STATUS_BAD_PORT`).
- `main_menu.gd::_join_by_address` pasa el campo por `RoomCode.resolve()`: un código mal tipeado muestra su mensaje
  y no conecta; código o IP conectan igual (ENet). El campo ahora dice "Código o IP del anfitrión".
- `hud/hud.gd::_refresh_session`: el anfitrión LAN ve `CÓDIGO  K7QM-4TXA` en vez de la IP.
- Textos: `HUD_SESSION_LAN`, `UI_MENU_HOST_IP`, `UI_MENU_JOIN_LAN_HINT`, `UI_MENU_STATUS_NEED_IP` cambiaron;
  claves nuevas `UI_MENU_STATUS_CODE_{LENGTH,CHARS,CHECK}` y `UI_MENU_STATUS_BAD_PORT`.
- Test nuevo `tests/test_room_code.gd`.

## Qué tiene que hacer Slatex

Nada. Si el panel de tripulación del depósito (S-507) muestra el código de la sala, usá
`RoomCode.encode(NetworkManager.lan_address(), NetworkManager.DEFAULT_PORT)` (vacío si no hay red local).
