# D-1928: murmullos de personajes en SynthAudio

- **Qué cambió:**
  - `modules/synth_audio/` (zona compartida): `SynthAudioMurmur` y el accesor `SynthAudio.murmur(voz, sílabas)`.
    Las voces son `boss` (por radio), `depot_boss`, `customer` y `driver`. Los sonidos que ya existían no
    cambian (el test golden sigue igual).
  - `CompanyVoice` (`scripts/presentation/`), agregado por `CompanyUi`. La Jefa abre cada día por radio.
- **Qué tiene que hacer Nacho:** nada. Para que un personaje hable desde un sistema nuevo, usar
  `CompanyVoice.say(voz, tr(clave), posición)`.
