# Revisar D-0840 — nombres de clientes

## Probar a mano
- Abrir el tablero de pedidos de un día: los clientes deberían verse como "Marta Rojas", sin repetirse seguido.

## Decidir al final
- Los nombres no se traducen (el pedido es el mismo en todas las pantallas). Si se quieren nombres por idioma, hay que mandar una clave y no el texto: cambia `Order` y el protocolo.
- El pozo (48 × 32) es mío; el usuario puede querer otros nombres.
